# The GM gate — implementation plan

**Spec:** `docs/specs/2026-10-03-gm-gate.md`. Inline execution, TDD per task, one fresh review of
the whole branch, one `feat(gm): …` commit after the full local CI sequence.

## Review focus

1. Gated text reaching any `table` route: titles, snippets, 404 messages, note lists.
2. A `[!gm]` callout nested in a list or another quote, and lazy continuation lines.
3. `%%` inside code spans and fences, and an unclosed `%%`.
4. A link that sits inside a gated block counting as "met".
5. The player view loading GM-lens data (the full note list) into the page.

## Tasks

1. **Core gate** — `packages/core/src/syntax/gm.ts`: `findGates(markdown): Gate[]`
   (`{ kind: 'callout' | 'comment'; start; end; startLine; endLine; revealed: number | null }`),
   `publicMarkdown(markdown, session): string`, `hiddenAt(gates, line, session): boolean`,
   `sessionNumberOf(frontmatter): number | undefined`, `isPublicNote(frontmatter): boolean`.
   Tests beside it.
2. **Callout kind** — `gm` in `CALLOUT_KINDS` and `CALLOUT_ALIASES`; `callout.gm` in both
   locales; the rust colour in `callouts.css`.
3. **Index** — DDL: `public_title`, `public_body`, `gates` columns, `notes_public_fts` with
   triggers; Drizzle schema; insert statement; `upsertNote` fills them from `publicMarkdown(…, 0)`;
   `INDEX_SCHEMA_VERSION` 6.
4. **PublicIndex** — `apps/server/src/store/public-index.ts`: sessions, visible set, list, search;
   `VaultIndex.publicView()` returns it.
5. **Routes** — `apps/server/src/routes/table.ts` (`sessions`, `notes`, `notes/*`, `search`),
   schemas, core API types, registered in the vault scope with `PublicIndex` only; OpenAPI.
   Leak test `apps/server/src/table.test.ts`.
6. **Web** — `RenderedLink.plain` in core (a link drawn as its text); routes `table` and
   `table/*` outside the GM layout; `TablePage` with slider, list, search, note; header link;
   i18n; styles.
7. **Example vault** — a GM block, a revealed block and a comment; e2e `table.spec.ts`.
8. **Docs** — DECISIONS, CHANGELOG, ROADMAP (tick three items), README, HANDOFF.
