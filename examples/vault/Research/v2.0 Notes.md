# v2.0 Notes

Notes on the second reorganisation of this vault, done over the last weekend of August. The first one, in March, made the campaign folder; this one made everything else make sense. Writing down what changed so that the next time I am tempted I can read this first.

## What changed

1. **Folder notes.** `Campaign/Campaign.md` is now the note for the folder, with a `color` field the graph can use. Nothing else got one; the research folder does not need a front door because [[Home]] is its front door.
2. **Daily notes by ISO date.** They were `Sep 15.md` and similar, which sorted by string. Now `2026-09-15.md`, which sorts by time and can be linked as [[2026-09-15]] without thinking.
3. **Dropped the Inbox folder.** Everything in it was either a fragment (now in [[Research/Archive]]) or dead. Fleeting notes go in the day's daily note, see [[Personal knowledge management#Capture]].
4. **Templates folder.** [[Templates/NPC]] and [[Templates/Session]] moved out of the campaign folder so they stop showing up as places or people.
5. **Tags trimmed.** From forty-one to about twenty. Nested tags for the campaign (`campaign/silverstadt/npcs`), flat ones for research.

## What I deliberately did not fix

Some of these are laziness and some are tests. The vault will be opened by a tool I am writing, and I want it to meet the mess a real vault has rather than one I have tidied for it.

- Two notes called Archive, in different folders
- A quest note whose frontmatter I broke while renaming it and have not repaired
- A note with an umlaut in the file name, one with an apostrophe, and this one, with a dot in its name that a careless tool will read as a file extension
- An empty note, `Daily/Scratch.md`, for pasting into
- A note that starts with a byte order mark because it came through a Windows editor, and one with Windows line endings for the same reason. I am not fixing them by hand; the tool can cope

## Frontmatter

The tags line above is written as a comma-separated string rather than a list, because that is how my first two hundred notes were written before I knew better, and a good parser accepts both. This note is the one that keeps the old style on purpose.
